# WikiPoly website

Landing page for WikiPoly Bar. React frontend, Node/Express API.

```bash
cd website
npm install
npm run dev
```

- Site: http://localhost:5173
- API: http://localhost:3000/api/product

Production:

```bash
npm run build
npm start
```

The core extension is free. **WikiPoly Signature** is a planned subscription for later research features; the waitlist is stored in memory on the server and is not persisted.
