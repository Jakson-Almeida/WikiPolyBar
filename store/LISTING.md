Description (paste into the Description* box)
---------------------------------------------
WikiPoly Bar puts your languages back on official Wikipedia articles.

Wikipedia’s Vector 2022 layout hid the language list in a collapsible control. If you read in more than one language, that means extra clicks every time you switch. WikiPoly Bar is a small floating bar on wikipedia.org with one-click buttons for the editions you actually use — for example Portuguese, English, and Spanish.

If the article exists in a saved language, you jump there instantly. If it does not, that button stays disabled. You never leave wikipedia.org, so you keep the Wikipedia account for that edition. There is no redirect to a third-party reader and no extra ads.

Split view opens two official editions side by side in the same tab so you can compare sections or check for missing information. Optional synced scrolling is off by default.

The bar is yours to place: drag it, minimize it, or close it. A gear menu lets you add, remove, and reorder preferred languages. Keyboard shortcuts (Alt+Shift+1 and similar) jump to language 1, 2, 3; Alt+Shift+S toggles split view.

WikiPoly Bar is free. Language preferences stay in Chrome sync storage. The extension does not sell data or run analytics.

Install, then open any Wikipedia article. The bar appears on the page. Pin the extension for quick access to the same settings.
